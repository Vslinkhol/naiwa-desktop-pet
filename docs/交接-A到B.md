### ⚠️ 一个我踩过、你也很可能踩的坑：素材路径是相对 **index.html** 的

`core/assets.js` 里的 `BASE = '../assets/'` 拼出来的字符串会赋给 `img.src` /
`video.src` / `new Audio(src)`。**这些相对 URL 是按「文档基地址」解析的，
不是按脚本文件的位置解析的。**

- ✅ 正确：从 `renderer/index.html` 看，`'../assets/'` → `<项目>/assets/`
- ❌ 错误：以为要相对 `core/assets.js` 算，改成 `'../../assets/'`
  → 从 `renderer/` 往上退两级，跑到**项目外面**去了

后果特别阴险：**所有素材静默 404，全部退回占位奶蛙**。而画面上「仍然有一只奶蛙」，
所以肉眼几乎看不出问题——我自己就是这么被骗过去的，最后是冒烟测试的
「待机必须是静态图」这条抓出来的（占位奶蛙的 SVG 有呼吸动画，真素材没有）。

现在 `assets.js` 的失败分支会 `console.error` 打出**实际请求的完整 URL**，
`console.error` 而不是 `console.warn` 也是这个原因：这条必须响。

> 顺带一提：`<script src="../assets/manifest.relax.js">` 那种写在 HTML 里的路径
> 本来就是相对文档算的，所以那份是对的。

## 3. `core/pet.js` 新增的原语

按 `00-协作约定.md` 第 4.1 节实现：

```js
await ctx.pet.setIdle();                    // 回本模式的静态待机
const ms = await ctx.pet.playOnce('laugh', { duration, hold, onEnd });
await ctx.pet.playLoop('run');
ctx.pet.stopLoop();
ctx.pet.isReacting();                       // → boolean
await ctx.pet.setOverlay('sweat', true);
ctx.pet.say('哈哈哈哈！', 1500);
ctx.pet.containsPoint(x, y);                // → boolean（已含跑步位移）
ctx.pet.lookAt(clientX, clientY);           // 传客户端坐标
await ctx.pet.preload(['laugh', 'run', 'sweat']);
const ms = await ctx.pet.performWithClones('laugh', { clones, spread, scale, opacity, fadeOut, onEnd });
```

⚠️ **`ctx.pet` 是一层门面，不是 `Naiwa.Pet` 本身。** 门面只暴露上面这些 +
第 4 节补的两个。`Naiwa.Pet` 上还有 `endReact()` / `isLooping` 之类的内部成员，
**那些不属于 `ctx` 契约**，别依赖它们。

## 4. `ctx` 与 `00-协作约定.md` 第 4 节的差异（**重点**）

| # | 差异 | 说明 |
| --- | --- | --- |
| 1 | **`ctx.pet.has(name, layer?)` 是异步的，必须 `await`** | 返回该槽位有没有**真正可用**的素材（`false` = 会用占位奶蛙）。`layer` 传 `'overlay'` 查叠加特效。**评审后由同步改成了异步**——同步版只看「清单里声明了没有」，路径写错时会把画风完全不同的占位卡通蛙当真素材挂上去。副作用：调用它会顺带完成挂载（等于预热） |
| 2 | **新增 `ctx.pet.root()`** | 返回主体元素 `#pet`。**只有它一个 DOM 例外**——因为跑步那种位移必须加在 `#pet` 本身（命中判定读的是它的 `getBoundingClientRect()`，那个 API 会算上元素自身的 transform）。如果你有别的地方想直接碰 DOM，先想清楚是不是也该走 `ctx` 扩展 |
| 3 | **新增 `ctx.mode`** | 只读，返回 `'relax'` / `'work'` |
| 4 | `ctx.pet.setIdle(mode?)` | 文档里是无参的。这里**多了一个可选参数**，不传 = 当前模式。所以你按文档写 `await ctx.pet.setIdle()` 是对的 |
| 5 | `ctx.pet.isReacting()` | 文档写的是方法，`Naiwa.Pet` 上是 getter，门面里已经适配成方法。**按文档写就行** |
| 6 | `ctx.log(msg)` | 会带 `[当前模式]` 前缀。切模式时前缀跟着变 |
| 7 | `ctx.pet.playLoop()` 的返回值 | 返回表现层内部句柄，**不要依赖它的形状**。当它是 `undefined` 就好 |

**没有实现、也不打算实现的**：`00-协作约定.md` 第 4 节里
「`ctx.panel` 只有工作模式用」——接口是全的（`open/close/toggle/isOpen/refresh`），
解压模式不调用而已。

## 5. 事件分发：`onPointerMove` 会被派发**两次**

这是最容易被坑到的一条：

- 点击穿透开启时，渲染进程**收不到** `mousemove`（窗口在忽略鼠标事件）。
- 所以主进程每 40ms 推送一次全局光标位置，`app.js` 拿它派发 `onPointerMove`。
- 同时，真实的 `mousemove` 也会派发同一个事件。

**结论：你的 `onPointerMove` 必须写成幂等的。**（同一个坐标处理两次不能出问题。）

其余事件都只派发一次：`onClick` 来自 `mouseup`，`onCpu` 每 2 秒一次，
`onIdleTick` 每 5 秒一次（`document.hidden` 时跳过）。

**另外**：鼠标悬停在奶蛙身上会被核心层当作「活动」，重置空闲计时。
你的打盹逻辑如果依赖 `idleMs`，行为是自洽的。

### 6.4 ⚠️ `run` 槽位目前是空的，原因和替代方案

**工作区里没有任何可用的跑步素材。** 两个可能来源我都实测过：

- `解压模式久不操作.gif` —— **抠得出来，但成不了循环**，两个独立的原因：
  1. **画质不够**：实拍背景只有靠色相分离，抖动噪点让边缘毛糙，肚子和手附近
     还会被咬出破洞（`bgLike` 的低饱和判据会吃掉接近白的奶油肚子边缘）。
  2. **结构上不是循环**：奶蛙是斜着跑远、镜头还在跟摇，占画面比例从 192×244
     缩到 240×100 并跑出画幅。可循环的精灵要求主体原地循环，这个素材做不到。

  > 补充说明：我一度以为橙色路面标线是致命问题（它和奶蛙同色，会粘在脚上长出
  > 一根橘色棍子）。加了「`g/r ≤ 0.62` 判为橙红」这条判据之后标线能去掉——
  > 奶蛙的黄 `g/r≈0.84`、深棕的脚 `≈0.78`，标线 `≈0.52`，分得开。
  > 但去掉标线也救不了上面那两条，所以结论不变。

  另外它的原始分辨率是 240×352，低于 380×380 的目标尺寸，放大后噪点更明显。

- `解压模式单点大笑.mp4` —— **全片没有跑步动作**。逐帧量脚底扫描线的
  「连续前景段」个数，恒为 1（两条腿从不分开），脚底始终贴地，是站着笑。

**所以解压模式的跑步是这么实现的**（`modes/relax.js` 的 `startRun`）：
没有 `run` 素材时**不退化成占位卡通奶蛙**（画风差太远，闲置 60 秒后突然换一只蛙
看起来像 bug），而是保留静态待机图，由代码加一个轻微的上下起伏，
配合本来就有的 ±80px 左右往返位移，读起来仍然是「自己在动」。

**拿到真正的跑步素材后**，把 `assets/manifest.relax.js` 里的 `run` 从
`{ kind: 'none' }` 改成下面这样即可，**代码一行都不用动**：

```js
run: { kind: 'file', src: 'relax/run.webp', loop: true },
// 或序列帧：
// run: { kind: 'frames', dir: 'relax/run', pattern: 'run_{n}.png',
//        start: 1, pad: 4, count: 12, fps: 15, loop: true, size: [190, 190] },
```

对你有影响的地方：**没有**。工作模式不碰 `run`。

### `__smoke.js` 怎么跑

```bash
npx electron --no-sandbox __smoke.js
```

⚠️ **`--no-sandbox` 在当前这台机器上是必需的**，否则 Electron 会以
`0x80000003` 直接崩掉（连 `--version` 都跑不起来）——这是嵌套沙箱的问题，
不是项目的问题。在你自己的机器上如果本来就能跑，可以去掉这个参数。

它 `require('./main.js')` 起真实主进程，把窗口隐藏掉，然后用**真实事件**驱动界面，
并做了几件不寻常但很有价值的事：

- 挂钩 `CanvasRenderingContext2D.drawImage`，**直接验证主体和 2 个分身
  是不是同一拍画同一张源图**（而不是只看它们「都动起来了」）
- 注册定时器计数器，用来发现切模式后的残留定时器
- 有正对照：验证「3 秒冷却」时会先确认冷却结束后**确实能**再次触发

| 现象 | 真实原因 |

## 8. 给你（🅱）的注意事项

1. **开工前先跑一遍解压模式当基线**（`docs/02-工作模式.md` 2.2）。
   基线确认之后，再发现解压模式坏了就能立刻确定是自己改的。
2. **`onPointerMove` 是双份的**，必须幂等（第 5 节）。
3. **`ctx.panel.isOpen()` 在核心层切到解压模式时会被强制关闭。**
   所以你的面板不需要自己处理「切模式要收起面板」——但 `deactivate()` 里
   仍然建议显式 `ctx.panel.close()`，别依赖别人的兜底。
4. **CPU 徽标仍然由 `app.js` 调用 `Naiwa.Panels.setCpu(v)` 更新。**
   这是拆分前就有的核心层 → 面板调用，我保留了，免得拆结构把徽标拆坏。
   你的 `onCpu` 只管流汗逻辑，不用管徽标。
5. **`ctx.pet.setOverlay` 的返回值**：`await` 它没问题，但它不返回有用信息。
6. **占位奶蛙的待机仍有呼吸动画**（`core/style.css` 原样搬过来的，
   属于计划内）。它只在素材缺失时出现；`idle_relax` 已经有真素材，是**静止**的。
   你放上 `idle_work.png` 之后工作模式也是静止的。
7. **别改 `assets/shared/idle_relax.png`**（那是共享素材）——
   要新姿势请放 `shared/idle_work.png`，并在 `manifest.work.js` 里声明。
8. **`__verify.js` 现在会检查 `index.html` 的脚本加载顺序。**
   如果你要加新脚本，请插进 `REQUIRED_SCRIPT_ORDER` 对应的位置，
   否则自检会报「加载顺序错了」——这是故意的，加载顺序错了程序会静默失效。

### 13.4 这两处改动的风险提示 ⚠️

`core/style.css` 和 `core/pet.js` 的改动**没有经过真机验证**
（Electron 在受限沙箱下起不来，见 §12.3 与 README 的环境说明）。静态上的把握：

- 槽位级 `hit` 只是把取值来源从 `MANIFEST.hit` 换成 `ANIMS[name].hit || MANIFEST.hit`。
  解压模式没有声明槽位级 `hit`，走的是回落分支，**与原行为完全一致**。

**下次能跑冒烟测试时，请优先跑 `__smoke.js`**（解压模式回归）：
修复 1 之后它应该是 **17 PASS / 0 FAIL / 1 SKIP**——S12 那个 FAIL 应该消失。

### 13.5 ⏸ 跑步功能暂时取消（主控裁决）

**`run` / 久不操作跑步整个停用。** 不是格式或画质问题，是**构图**：

把 `解压模式久不操作.gif` 逐帧拆开量过——奶蛙占画面的像素比例从 **7.6% 崩到 0.5%
（约 15 倍）**，第 48 帧基本跑出画幅，背景是实拍公路（灰路面 + 树 + 天空 + 橙色标线），
没有纯色可 key。可循环的精灵硬性要求主体**原地、等大**，这条素材做不到。

（橙色路面标线确实和奶蛙同色，但可用 `g/r` 比值分开：标线 ≈0.52、奶蛙 ≈0.84。
这一条 🅰 的判断是准的。**GIF 格式本身完全不是障碍**，转任何格式都是常规操作。）

**处理方式——代码故意保留，只加开关：**

| 位置 | 改动 |
| --- | --- |
| `modes/relax.js` | 新增 `CONFIG.RUN_ENABLED = false`，并把它加进 `onIdleTick` 的起跑判据 |
| `assets/manifest.relax.js` | `run` 槽位保留（`kind:'none'`），注释改成「已取消 + 如何恢复」 |

**为什么不删代码**：项目**没有版本控制**，删掉就找不回来了。保留 + 开关，
代价只是 100 多行暂时不执行的代码，收益是恢复时零成本。

**恢复只需两步，不用改代码**：
① `CONFIG.RUN_ENABLED` 改 `true`；② `manifest.relax.js` 的 `run` 换成真素材声明。

**对验收的影响**：`docs/01` 第 8 节里「闲置 60 秒 → 开始跑步」和「跑步到一半切模式」
两条已标记为随功能取消；新增一条「闲置 60 秒后奶蛙保持静止」。

**⚠️ 这意味着解压模式现在少了一个功能**，`README` 的功能表和已知限制都同步标注了。
